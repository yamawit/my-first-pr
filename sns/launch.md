| 候補 | ハンドル例 | ひとこと |

| タワマン相場ちゃんねる | @towaman_souba | 内容がひと目で分かる。無難で強い |
| 億ションウォッチ | @okushon_watch | 「億」で価格帯が伝わる |
| 47タワマン | @47towaman | 47都道府県シリーズと直結。覚えやすい |
| タワマン値段図鑑 | @towaman_zukan | 「図鑑」で集めたくなる感じ |
| 地元の一番高いタワマン | @jimoto_towaman | 「あなたの地元は？」の締めとつながる |

**おすすめ：「47タワマン」**。シリーズ名がそのままアカウント名になり、動画の締め（「あなたの地元は？」）とも合います。全県終わったあとも「47都道府県の〇〇ランキング」で続けられます。

> 取る前に、各サービスで同じ名前が空いているか確認してください。

## 3. X投稿文

### A. 一覧画像の改良版（1000いいねの画像の作り直し）

**パターン1：問いかけ**
```
47都道府県で「一番高いタワマン」を全部調べました。

1位 東京 41億8,000万円
最下位 青森・秋田 1億9,800万円

その差、約21倍。
あなたの地元はいくらでしたか？

※掲載価格をもとに作成（2026年10月確認）
```

**パターン2：意外性**
```
宮城のタワマンが、千葉より高い。

47都道府県の「一番高いタワマン」を並べたら、
意外な逆転がいくつもありました👇

※掲載価格をもとに作成（2026年10月確認）
```

**パターン3：数字のインパクト**
```
日本一高いタワマン、41億8,000万円。

平均年収で約900年分。
宝くじ1等（7億円）を5回当てても買えません。

47都道府県ぜんぶ並べました👇
```

### B. 動画の告知（#01 東京の回）

```
日本一高いタワマン、いくらか知ってる？

答えは41億8,000万円。
……でも、最上階は噂では「200億円」とも。

60秒で解説しました🏙
（動画URL）

#タワマン #麻布台ヒルズ #不動産
```

### C. 投稿のコツ

- **最初の1行で数字か問いかけ**を出す（タイムラインで止まってもらうため）。
- 画像は**1枚目に一覧、2枚目にTOP5**の構成にすると保存されやすいです。
- **出典と確認日**を必ず入れる。前回の画像で一番ツッコまれやすかった部分です。
- 噂の話（200億円）は、**「噂では」「とも言われています」**と言い切らない。
- 宣伝（アフィリエイトなど）を含む投稿には **#PR** を付ける。
