# 1県1本 ショート動画テンプレート（60秒以内）

## 構成（秒数の目安）

| 秒 | パート | 中身 |
|---|---|---|
| 0〜3 | つかみ | 「〇〇県で一番高いタワマン、いくらか知ってる？」 |
| 3〜10 | 物件紹介 | 物件名・場所・階数・竣工年（空撮映像） |
| 10〜20 | 価格発表 | 価格を大きくテロップ。「ドン！」の効果音 |
| 20〜40 | 比較 | 平均年収で何年分か／宝くじ何回分か／県内の平均マンション価格との差 |
| 40〜52 | 自分の意見 | ツッコミ・感想（収益化対策の「独自の付加価値」） |
| 52〜60 | 締め・予告 | 「あなたの地元は？コメントで！」＋次の県の予告 |

## 公開前チェックリスト

- [ ] 物件が実在するか（販売サイト・公式サイトで確認）
- [ ] 価格の出典URLと確認日を控えた
- [ ] 比較の計算を電卓で確かめた
- [ ] 映像は Google Earth Studio などで作り、「Google」のクレジットを入れた
- [ ] 住人・表札・部屋番号が映っていない
- [ ] 読み上げソフト（VOICEVOX等）のクレジットを入れた
- [ ] 宣伝を含む場合は #PR を付けた

## ネタ切れ対策リスト

- 新築時から価格が一番上がったタワマン TOP10
- 坪単価ランキング
- 駅から一番近いタワマン
- 地方の「県内で一番高い建物」シリーズ
- 同じ価格で東京と地方ならどっちが広い？
- 視聴者コメントで来た県をリクエスト回で紹介
